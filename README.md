# NexusPOS

### Point-of-Sale & Business Management Platform

NexusPOS is a web-based business management platform for managing
sales, inventory, customers, staff, and multi-location operations.

**[🚀 Live Demo](https://mtapps.netlify.app/)**

## ✨ Features

- 🛒 **Point of Sale** — Process and track sales transactions.
- 📦 **Inventory Management** — Manage products and stock levels.
- 🔄 **Stock Transfers** — Move inventory between locations.
- 🏪 **Multi-Location Support** — Manage inventory across multiple stores.
- 👥 **Customer & Staff Management** — Manage operational records.
- 📊 **Business Dashboard** — Monitor sales and inventory activity.

---

## 🛠️ Tech Stack

**Frontend:** React · JavaScript · Tailwind CSS · Webpack

**Backend:** Node.js · Express.js · REST API

**Database:** MongoDB

**Deployment:** Netlify
